# 🧸 Khushiii & Shomayyy's Pink Teddy Wonderland 💖

A cozy, animated, mobile-responsive love page created with all my heart by **Shomayyy** for **Khushiii** (*"My Latu"*).

---

## ✨ Features

- 💌 **Entrance Sorry Note & Ribbon Untie:** *"Hey bby sorry yaar maaf krde baby"* with an apologetic cartoon teddy bear ("Kaan Pakad Ke") that softly unlocks the audio player.
- 🎶 **Background Music Player:** Plays *"Die With A Smile"* by Lady Gaga & Bruno Mars with rotating vinyl record animation, progress bar, and Web Audio API fallback.
- ⏳ **Live Milestones & Clocks:**
  - 💫 Days since we first knew each other (20 November 2023)
  - 💖 Days in relationship (7 August 2024)
  - 📍 The magical first meet (28 October 2024 at 13:42)
  - 🎂 Countdown to her birthday (10 September)
- 📖 **Storybook Milestones & Trait Cards:** Highlighting her never-give-up spirit, cute pouts, smile, eyes, and unconditional love.
- 📸 **Interactive 3D Polaroid Wall & Lightbox:** Interactive polaroids with handwritten captions, rotation stamps, and full-screen zoom.
- 🫙 **Magical Love Jar:** Draw unlimited little sweet love notes and hugs.
- 🏃‍♂️ **Dodging "No" Question Game:** Try to click "No" and watch it run away, while "Yes! Always 💖" explodes in heart confetti.
- 💌 **Wax-Sealed Love Letter:** Click the royal wax seal to reveal the handwritten letter and heartfelt message.
- 📱 **Mobile First & Responsive:** Optimized touch gestures and fluid layouts for phones, tablets, and desktops.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/Shomay12/My-personal.git
cd My-personal

# Start the local server
node server.js
# Or
npm start
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

## 🌐 Automatic GitHub Pages Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically scans all photos and deploys the site to GitHub Pages whenever changes are pushed to `main`.

### To Enable GitHub Pages:
1. Go to repository **Settings** > **Pages**
2. Under **Build and deployment** > **Source**, choose **GitHub Actions**
3. Push to `main` and your website will go live automatically!
